==== Monac ===
   [[USAGE]]
monac [options] file...
Options:
    --help                                      (-h)    Display Usage.
    --version                                   (-v)    Display Version.
    --vlex <input_file> [output_file]           (-l)    Dumps tokens from input file into output file, if no output file, dumps it to stdout.
    --vast <input_file> [output_file]           (-p)    Dumps ast from input file into output file, if no output file, dumps it to stdout.
    --vasm <input_file> [output_file]           (-a)    Dumps generated assembly from input file into output file, if no output file, dumps it to stdout.
    --output <exectuable_name>                  (-o)    Place the output of the compilation into a file by the name <executable_name> if no name is given, monac is free to create a default (named "default") executable.
    --input  <input_file...>                    (-i)    Pipe a variadic list of input files to be compiled.
EXAMPLES:
    monac --input input.mx
    monac -o output -i input.mx
    monac --vlex input.mx
    monac --vast input.mx ast.txt
    monac --vasm input.mx assembly.s
